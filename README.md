# PolarisView — 偏振数据分析与透明预处理工作台

[English README](README.en.md)

PolarisView 是一个 Chrome 扩展，用于半波片旋转测量的偏振数据预览、可追溯预处理、统计分析、马吕斯模型拟合和学术报告导出。

## 应用场景

PolarisView 面向旋转半波片—检偏器强度扫描等偏振光学实验，尤其适合：

- 快速比较多段旋转扫描在峰位、幅度和周期上的一致性；
- 明确呈现探测器暗背景、基线处理和截断状态，避免只保留“处理后曲线”；
- 将连续扫描自动划分为互不重叠的 360° 独立周期，计算均值、SD、SE、RSD、调制度代理和消光比；
- 生成用于论文作图、组会汇报、OriginPro 二次作图及实验记录归档的数据、图表和 HTML/PDF 报告。

## 核心功能

### 数据导入与质量门

- 支持表格逐点编辑、文本粘贴、拖放 `.txt` / `.csv` / `.dat`，自动尝试 UTF-8 与 GBK 解码。
- 支持 `x, intensity` 两列或单列强度数据；严格拒绝混合表头和多余数值列，并报告接受/拒绝行及原因。
- 自动检查有效点数、角度覆盖、重复 x、乱序、周期一致性、源点重复计入、负值截断、相位锁定和拟合矩阵稳定性。
- 图例中隐藏某个数据组会将其同步排除在均值、SD/SE、平滑与经验谐波拟合之外；重新显示后会立即重新参与计算。
- 默认使用“独立周期”模式，保证每个原始点只参与一次统计；旧滑动窗口模式仅用于形状诊断。
- `blocked` 质量状态会停止 KPI 和物理参数报告，原始数据仍可作为诊断材料导出。
- 工作台首次打开保持空白；`Pol.txt` 仅作为可选示例，避免示例曲线与用户实测数据混淆。

### 透明预处理

默认采用原始直通，不推断暗场且不截断负值。可选提供恒定偏置、AsLS、airPLS、SNIP、Rubberband、多项式、线性漂移和滑动极小值等背景模型。界面显示当前方程、参数、背景占比和净峰值；导出时同时保留：

1. 原始强度 (`Raw_Y`)
2. 估计基线 (`Baseline_Y`)
3. 未截断净值 (`Unclamped_Subtracted_Y`)
4. 显示/分析净值 (`Displayed_Subtracted_Y`)

### 极坐标、拟合与统计

- 生成极坐标图、角度展开图、基线图、残差图和双联视图。
- 在质量门允许报告时，以浅灰虚线参考环标示当前 `Imin` / `Imax`；参考环不参与拟合。
- 提供高斯、Savitzky–Golay、傅里叶和滑动平均平滑显示，以及周期样条曲线。
- 使用经验谐波最小二乘模型评估强度曲线一致性，检查秩与条件数，并给出自由度、R²、RMSE、系数不确定度、θ₀/调制度代理 95% CI、残差和离群点提示。
- 统计独立周期的逐角度均值、SD、SE、RSD、消光比和调制度；单周期不提供伪造的 SE。

## 导出与协作

| 输出 | 内容 |
|---|---|
| PNG / SVG | 当前图形的出版级图像 |
| CSV | 原始、基线、未截断/显示净值与统计数据 |
| Excel (`.xlsx`) | `OriginPro_Data`、`Raw_Preprocessing`、`Processing_Notes`、`Analysis_Recipe` 四个数据与溯源工作表；不内嵌绘图 |
| HTML | 内嵌图像、表格和处理记录的独立离线报告 |
| PDF | 在报告页打开系统打印窗口后选择“另存为 PDF” |

`OriginPro_Data` 的 A 列为角度，B–D 为最多三个独立周期槽位，E–I 为均值、误差与样本数，可直接作为 OriginPro 作图数据源。工作簿不内嵌 Excel 图表。

所有导出记录 Analysis ID、应用版本、源文件名、编码、SHA-256、解析诊断、实验元数据、分组模式、算法参数、参与/排除组和质量状态；“导出分析配方 JSON”可独立归档完整处理配置。

## 安装与使用

1. 从本仓库下载或克隆源码。
2. 在 Chrome 打开 `chrome://extensions`，启用“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本项目根目录。
4. 点击扩展图标，或打开工作台后导入数据。确认角度倍率和独立周期分组，再按实验依据选择是否进行基线处理。
5. 在“数据质量与结论边界”卡片检查警示；若周期一致性偏低，请先核查 x 列、采样顺序、角度零位和仪器状态。

## 科研解释边界

本工具提供的是数据处理与模型一致性证据，并不自动替代仪器校准或完整偏振测量。尤其应注意：

- 以 `min(y)` 作为常数偏置只是数据驱动的显示基准，不等同独立暗场测量。
- 启用负值截断可能抬高处理后的 DoLP 或消光比；请同时检查未截断列。
- 自动相位锁定只用于可视化对齐，不能替代机械零位校准，也不应用于评价真实重复性。
- 单次强度扫描与经验谐波拟合不能独立标定波片延迟或完整 Stokes 矢量。严谨结论应结合暗场、空白、已知输入态、检偏器零位及重复测量。
